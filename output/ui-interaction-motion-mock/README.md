# UIインタラクションモーションモック

既存の会話中心UIのレイアウトを変えず、次の確定済みモーションだけを確認する独立モックです。

- 操作用ひし形をホバーすると、右下から左上へ明るい青、白系ハイライト、淡い紫のガラス反射が約167msで1回走る。
- 選択中のひし形にも反射を表示する。
- ライトテーマを初期状態とし、明るい背景でも反射を認識できる強さにする。
- メイン画面のひし形は押下中に3%縮む。
- メイン画面の「設定」をクリックすると、選択したひし形だけが約500msで発光・微拡大・消滅する。
- クリック直後から、選択確定演出と設定画面への遷移を同時並行で開始する。
- 設定画面は、テーマ別の上部グラデーションと7個のひし形の順次フェードインを同時に開始し、約750msで表示を完了する。
- 設定画面のひし形は約33ms間隔で、画面上の左から順にフェードインを開始する。
- 設定画面の7個のカテゴリ用ひし形は、共通の間隔値で横方向へ均等に配置する。
- 同じ段のカテゴリ用ひし形は接触させず、上下段の余白と釣り合う均等な横方向の余白を設ける。
- メイン画面の「会話」を左上、「設定」を下中央へ入れ替える。
- メイン画面の3つのひし形が内包するハート形のシルエットは維持する。
- ハート形の配置枠はひし形1個を基準に幅2個分、高さ1.5個分とし、表示サイズが変わっても同じ比率で拡大・縮小する。
- 設定・性格・会話の集中画面では下部ナビゲーションを隠し、右上の `×` だけを表示する。
- 集中画面を開くと背面をフォーカス対象外にして `×` へフォーカスを移し、閉じると「チャット」のひし形へ戻す。
- 表示演出中でも `×` または `Esc` で直ちに閉じられるようにする。
- このレビュー用モックでは、OSの `prefers-reduced-motion` にかかわらず確定済みの通常速度を強制する。本番実装では reduced motion 用の代替動作を別途設計する。

## 確認方法

1. このディレクトリで `node serve.mjs` を実行し、`http://127.0.0.1:4179/` を開く。
2. メイン画面下部の各ひし形へポインターを載せ、反射方向と強さを確認する。
3. 「設定」をクリックし、選択確定演出と設定画面の表示演出を確認する。
4. 設定画面右上の `×` または `Esc` でメイン画面へ戻り、再生を繰り返す。
5. 設定画面のテーマ選択、または `T` キーでライト／ダークを切り替える。

## 対象外

- 本番アプリのReactコンポーネントや共有CSSへの組み込み
- 実装値の最終調整
