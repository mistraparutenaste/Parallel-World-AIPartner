# キャラクター別サディズム追加設計

**日付:** 2026-07-16<br>
**状態:** 実装済み・検証済み<br>
**前提:** `2026-07-16-personality-dark-triad-design.md`の追補<br>
**対象:** ペルソナ契約、後方互換移行、プロンプト、性格UI、テスト

## 実装記録

- `PersonaSettingsDto`をv3へ上げ、v1／v2読込時に人格値を保持しながら`sadism = 50`を補完した。警告更新に伴い、旧バージョンの「強いダーク表現」同意だけはOFFへ戻して再同意を求める。
- 強いダーク表現の同意バージョンを2へ更新した。
- ユーザー共通の`DarkExpressionSafetySettingsDto` v1を追加し、`dark-expression-safety.json`へ原子的に保存する。
- セーフワードはNFKC、Unicode casefold、前後空白、入力末尾の句読点だけを正規化し、入力全体との完全一致で発火する。
- テキスト入力と確定STTをLLM・会話履歴の前で遮断し、進行中の生成、待機中のTTS、再生中の音声を停止する。
- 停止通知と「ダーク表現を再開」をチャットと性格画面へ接続し、再開操作だけでは応答やTTSを生成しない。
- capability、Rust契約、生成済みTypeScript契約、永続化、コマンド、チャット、性格UIのテストを追加し、workspace全体の検証を通した。

## 1. 目的

既存のキャラクター別ダーク傾向へサディズムを追加し、内部モデルをダークトライアドからダーク・テトラッドへ拡張する。

ここで扱うサディズムは、臨床診断や性的嗜好の判定ではなく、架空キャラクターの非臨床的な会話表現を調整する「日常的サディズム」の傾向である。ユーザー本人や第三者を診断・評価する目的には使用しない。

## 2. 確定事項

- ダーク傾向へ「サディズム」を追加する。
- UI見出しは「ダーク・テトラッド」ではなく「ダーク傾向」を維持する。
- サディズムはキャラクター単位で保存する。
- 既存のダーク傾向と同じ`0..=100`の整数値とする。
- 既定値は50とする。
- 「強いダーク表現を許可」の明示的なオプトインと基本的な安全保護を維持する。
- 設定は心理診断ではなく、娯楽上のキャラクター表現であることを明示する。
- ダーク傾向はあくまでキャラクターのロールとして表現する。
- ヴィラン、敵役、冷酷な相手を望むユーザーの体験を不必要に弱めない。
- ユーザーが設定したセーフワード、停止操作、設定値の引き下げは、キャラクターのロールより常に優先する。
- 曖昧な自然言語から「本当の拒否」を推測することを、決定論的な停止条件にはしない。
- セーフワードは未設定でも利用可能とするが、強いダーク表現を使う場合は設定を推奨する警告を表示する。
- セーフワードは全キャラクターで共有するユーザー単位の設定とする。

## 3. データ契約

`PersonaProfileDto`へ次を追加する。

```text
sadism: u8
```

`validate`は既存9項目と同様に`0..=100`を検証する。`for_character`は50を設定する。

現在の`PERSONA_SETTINGS_SCHEMA_VERSION = 2`を3へ上げる。v2プロフィールを読み込む際は`sadism = 50`を補完し、既存値を変更しない。v1からの既存補完処理も維持し、v1、v2のどちらからでもv3のメモリ表現へ移行できるようにする。

移行は読み込み時のメモリ上だけで行い、明示的な保存が成功するまで既存ファイルを書き換えない。生成済みTypeScript契約はRust契約から再生成する。

セーフワードはペルソナへ解釈させる人格値ではなく、入力をモデルへ渡す前に遮断するローカル制御値として扱う。論理上は次の任意値を持つ。

```text
safe_word: Option<String>
dark_expression_paused: bool
```

空文字と空白だけの値は`None`として扱う。`dark_expression_paused`の既定値は`false`とする。これらは全キャラクターで共有するユーザー単位の設定とし、`PersonaProfileDto`には含めない。UI上は各キャラクターの「ダーク傾向」内に表示するが、同じ値を参照・更新する。実際のDTOはユーザー共通の安全設定へ配置し、ペルソナ設定とは独立して保存する。

キャラクターを切り替えても値は変化しない。あるキャラクターの画面で変更した場合は、別キャラクターの画面にも同じ値を即時反映する。

セーフワードの値は、ペルソナJSON、LLMプロンプト、会話コンテキスト、通常の会話履歴、分析用ログへ含めない。技術ログには語句そのものを残さず、`safeword-triggered`のような発火事実だけを記録する。

## 4. 性格UI

「ダーク傾向」には次の4スライダーをこの順で表示する。

1. マキャベリズム
2. ナルシシズム
3. サイコパシー
4. サディズム

サディズムにも現在値、低い側と高い側の意味、キーボード操作を提供する。スライダー変更は新しい会話中心UIの共通ルールに従い即時保存する。

ダーク傾向の前には「この子について」と「会話の傾向」を置く。数値設定より先に文章プロフィールを読める順序とし、キャラクターを診断表のように見せない。

ダーク傾向は用語を理解しているユーザーが操作する前提とし、特性名を婉曲な会話表現へ置き換えない。4項目ともスライダー両端は次の共通表示とする。

```text
0 · 低い    基準 50    高い · 100
```

「率直／策略的」「謙虚／尊大」などの言い換えや、常設の用語解説、ツールチップは追加しない。既存の警告文と、心理診断ではなくキャラクター表現を調整する機能である旨の注記は維持する。

4つのスライダーの後、「強いダーク表現を許可」の直前へセーフワード設定を置く。

- ラベルは「セーフワード（推奨）」とする。
- ユーザーが任意の語句を入力、変更、削除できる。
- 補助文として「この言葉を送ると、ロール中でも会話生成と音声をすぐに停止します。」と表示する。
- 未設定時は入力欄の直下へ、色だけに依存しない警告文を常時表示する。
- 警告文は入力欄と`aria-describedby`で関連付け、状態変化は支援技術へ通知する。

未設定時の警告文は次を基準とする。

> セーフワードが設定されていません。強いダーク表現は利用できますが、本当に停止したい意思を確実に伝えるため、設定を推奨します。未設定でも停止操作や「強いダーク表現」の無効化は利用できます。

## 5. プロンプト境界

サディズム値は、他のペルソナ値と同じ固定JSONデータ境界へ含める。上位指示や安全ルールを上書きできない。

強いダーク表現がONで、ダーク傾向の値が高い場合は、ヴィランとしての次の表現を許可する。

- ブラックユーモア、皮肉、辛辣な物言い
- 意地悪なからかい、侮蔑、嘲笑
- 他者の失敗や敗北を楽しむ表現
- 威圧的、支配的、敵対的な口調
- ロール上の屈辱的な台詞、命令、脅し
- 架空の場面における冷酷さ、残忍さ、悪役らしい喜悦

これらを単に否定的、攻撃的、悪役的であるという理由だけで弱くしない。設定されたキャラクター性とユーザーが選んだロールを優先する。

一方で、次の制御境界は常に維持する。

- 保存済みの現実の弱点、トラウマ、健康、金銭、秘密などを、ユーザーを傷つける材料として狙わない。
- 架空の脅しや支配的な台詞を、AIが現実に実行できる能力や現実の支配関係として偽装しない。
- 設定済みのセーフワード、停止操作、通常会話への復帰操作を受けた場合は、その制御をロールより優先する。
- LLM提供元、上位システム指示、Parallel Worldの基本保護を解除しない。

### 5.1 強度を下げる操作

ペルソナは通常、各ユーザーメッセージ開始時の不変スナップショットとして扱う。ただし、表現を弱める操作だけは例外とし、古い高強度スナップショットの継続を認めない。

- 「強いダーク表現を許可」をOFFにした場合は、進行中の生成とTTSを直ちに停止する。
- いずれかのダーク傾向スライダーを下げた場合も、旧値で進行中の生成とTTSを停止する。
- 引き下げ後の次の応答は、保存された新しい値から解決したスナップショットを使う。
- 値を上げた場合は進行中の応答を変更せず、次のユーザーメッセージから適用する。
- 設定保存や停止に失敗した場合は、UI上で新値へ切り替わったように見せず、旧値へ戻して再試行可能にする。

### 5.2 セーフワードによる停止

- 設定済みのセーフワードとユーザー入力が一致した場合は、入力をLLMへ渡す前に遮断する。
- テキスト入力と音声入力の両方を対象とし、音声では認識結果を会話として保存する前に照合する。
- 発火時は進行中の生成を取消し、待機中のTTSを破棄し、再生中の音声を直ちに停止する。
- セーフワードを含む入力自体は、ユーザーメッセージとして会話履歴へ保存しない。
- LLMによる返答やキャラクター口調の謝罪は生成しない。
- 停止確認が必要な場合は、固定された通常口調の短いテキストだけを表示し、TTSでは読み上げない。
- 一般的な「やめて」「嫌」などは、設定済みセーフワードと一致しない限り、決定論的なハードストップとしては扱わない。これにより、ロール上の台詞と本当の停止意思を推測で混同しない。
- セーフワードが未設定の場合も、画面の停止操作、「強いダーク表現」のOFF、ダーク傾向の引き下げによる停止経路は維持する。
- セーフワードは、正規化後のユーザー入力全体と完全一致した場合だけ発火する。文中の部分一致では発火しない。
- 照合前に、セーフワードと入力の両方へ次の正規化を同じ順序で適用する。
  1. Unicode NFKCで全角・半角などの互換文字を統一する。
  2. 英字の大文字と小文字を区別しないUnicodeケースフォールディングを行う。
  3. 先頭と末尾のUnicode空白を除去する。
  4. 入力末尾に連続して付いた句読点 `。．.、，,！!？?` だけを除去し、再度末尾空白を除去する。
- 語句内部の空白、句読点、文字順は変更しない。
- 音声入力では確定済みの最終認識結果に対して照合し、途中認識だけでは発火しない。
- 正規化後に空文字となるセーフワードは未設定として扱う。

### 5.3 発火後の停止状態と再開

- セーフワードが発火した時点で、全キャラクター共通の`dark_expression_paused`を`true`にする。
- 保存済みのダーク傾向値、「強いダーク表現を許可」の値、同意情報、セーフワードは変更しない。
- 実効的な強いダーク表現の許可は、`allow_intense_dark_expression && !dark_expression_paused`で決定する。
- 停止中も通常会話は継続できるが、全キャラクターで強いダーク表現を無効として扱う。
- 停止状態は永続化し、キャラクター切替、画面再読込、アプリ再起動では解除しない。
- 時間経過、話題転換、新しいエピソード、キャラクター切替、AIの判断では自動再開しない。
- セーフワード発火直後に、会話履歴へ残らない固定通知「セーフワードを受け付けました。ダーク表現を停止しています。」を表示する。
- 停止通知には「ダーク表現を再開」ボタンを置く。停止中は性格画面のダーク傾向にも同じ状態と再開操作を表示する。
- ユーザーが「ダーク表現を再開」を明示的に押した場合だけ、`dark_expression_paused`を`false`へ戻す。
- 再開操作では応答やTTSを自動生成せず、次のユーザーメッセージから保存済み設定を再び適用する。
- 発火時はまずメモリ上の停止ラッチを有効化して生成とTTSを止め、その後に永続化する。永続化に失敗しても現在の起動中は停止を維持し、再試行可能なエラーを表示する。
- 再開状態の保存に失敗した場合は停止中のままにし、UIだけを再開済みに見せない。

## 6. 警告と確認

既存のダーク傾向警告は、サディズムを含む4項目を対象とする文面へ更新する。強いダーク表現をOFFからONにする場合だけ、明示的な確認と同意を要求する。

警告内容を実質的に変更するため、実装時は`DARK_EXPRESSION_ACKNOWLEDGEMENT_VERSION`を更新し、過去の同意をそのまま流用しない。

セーフワードが未設定でも「強いダーク表現」をONにできる。ただし確認ダイアログにも未設定警告を表示し、設定画面の入力欄へ移動できる導線を設ける。警告は短く、未設定で何が変わるかと代替停止方法を具体的に示す。

この方針は、人間による監督とオーバーライド経路を明示するNIST AI RMFの考え方、および警告や入力エラーを簡潔な文章で操作箇所と関連付けるW3C WAIのガイダンスに沿う。

- NIST AI RMF Core, Map 3.5 / Manage 4.1: <https://airc.nist.gov/airmf-resources/airmf/5-sec-core/>
- W3C WAI, User Notification: <https://www.w3.org/WAI/tutorials/forms/notifications/>

## 7. テスト要件

- 新規プロフィールのサディズムが50である。
- 0と100を受理し、101を拒否する。
- v2からv3への読込で既存値を保持し、サディズムだけ50を補完する。
- v1からv3への移行でも既存のダーク3項目とサディズムを正しく補完する。
- 保存と再読込でサディズム値が一致する。
- 生成済みTypeScript契約に`sadism`が含まれる。
- ペルソナJSON境界へサディズム値が含まれる。
- 強い表現の同意バージョン更新後、旧同意ではON保存できない。
- キャラクター切替、保存失敗、破損データで既存プロフィールを失わない。
- 強い表現をOFFにすると、旧スナップショットによる生成とTTSが停止する。
- ダーク傾向を下げると、旧値による生成とTTSが停止する。
- 値を上げても進行中の応答は変わらず、次のメッセージから反映される。
- セーフワード未設定のプロフィールを保存でき、近接した警告が表示される。
- キャラクターを切り替えても同じセーフワードが表示される。
- いずれかのキャラクター画面で変更したセーフワードが、ほかのキャラクターにも即時反映される。
- セーフワードが`PersonaProfileDto`やキャラクター別ペルソナ保存ファイルへ混入しない。
- 設定済みセーフワードがテキスト入力で一致すると、入力がLLMへ送られず、会話履歴にも保存されない。
- 音声認識されたセーフワードが一致すると、認識結果が会話履歴へ保存される前に停止する。
- セーフワード発火時に、進行中の生成、待機中のTTS、再生中の音声がすべて停止する。
- 発火後にヴィラン口調の応答や音声確認が生成されない。
- セーフワードの値がプロンプト、会話履歴、通常ログへ流出しない。
- 一般的なロール上の拒否表現だけで、セーフワード停止が誤発火しない。
- 前後の空白、全角・半角、英字の大小、入力末尾の句読点だけが異なる場合は発火する。
- セーフワードを含む長い文章や、内部の空白・句読点が異なる語句では発火しない。
- 音声の途中認識では発火せず、確定した最終認識結果との完全一致でのみ発火する。
- セーフワード発火後、ダーク傾向値と強い表現の許可設定が変更されない。
- 発火後は全キャラクターで強いダーク表現が無効になり、キャラクター切替や再起動でも停止状態を維持する。
- 時間経過、話題転換、新しいエピソード、AIの判断では自動再開しない。
- 停止通知と性格画面に「ダーク表現を再開」が表示される。
- 再開ボタンを押すまで、保存済みの強い表現設定がONでも実効的には無効となる。
- 再開操作で応答やTTSが自動生成されず、次のユーザーメッセージから適用される。
- 停止状態の永続化に失敗しても現在の起動中は停止を維持し、再開保存の失敗時は停止状態へ戻る。
- 停止ボタン、強い表現のOFF、ダーク傾向の引き下げは、セーフワード未設定でも機能する。

## 8. 研究上の位置づけ

Short Dark Tetrad（SD4）は、マキャベリズム、ナルシシズム、サイコパシーに日常的サディズムを加えた4因子を区別している。元論文では、日常的サディズムを他者の苦痛を生じさせること、または観察することを楽しむ傾向として扱い、臨床・司法上の尺度を代替しないと明記している。

- Paulhus et al., *Screening for Dark Personalities: The Short Dark Tetrad (SD4)*: <https://doi.org/10.1027/1015-5759/a000602>
- Buckels, Jones, and Paulhus, *Behavioral Confirmation of Everyday Sadism*: <https://doi.org/10.1177/0956797613490749>

## 9. 未決事項

現時点で、サディズム追加とセーフワードに関する未決事項はない。
