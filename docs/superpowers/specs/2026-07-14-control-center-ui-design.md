# 管理ウィンドウ統合・フラットUI設計

## 目的

設定ウィンドウを会話・設定・ログの共通管理画面へ拡張し、会話を任意にポップアウト／再格納できるようにする。Live2Dキャラクター窓は既存機能を保ったまま、透明領域にネイティブウィンドウの背景・境界・影を一切残さない。

## 画面構成

- 管理ウィンドウは左サイドバーの「会話・設定・ログ」で切り替える。
- 会話は送受信画面。既存chat窓へポップアウトでき、閉じる操作は再格納として扱う。
- 設定は「音声・AI・キャラクター・データ・診断・更新」に整理する。Runtime Healthとクラッシュ診断は診断内に残す。
- ログは「会話ログ」と「技術ログ」の2タブ。会話ログはSQLite履歴の閲覧専用、技術ログは現行parallel-world.logの閲覧専用とする。
- 管理窓とchat窓はOS標準タイトルバーを維持する。

## ビジュアル

- サイドバー150px、角丸12px、密度100%、ミント系アクセントを基準とする。
- system／light／darkを提供し、systemはOSテーマ変更へ追従する。
- 共通トークンと部品で入力、ボタン、カード、状態、空状態、エラーを統一する。
- タブはWAI-ARIA Tabs Patternに従い、矢印、Home、Endで操作できる。

## 状態とデータ

- config/ui.jsonへschema_version、theme、chat_placementを保存する。初回および破損時はsystem＋docked。
- 会話イベントは管理窓とchat窓の両方へ配信し、非表示側も同期する。
- 会話ログは100件ずつページングし、最大200文字の検索語をSQLite側へ適用する。
- 技術ログは現行ファイルだけを初回末尾128KiB、以後バイトカーソルで差分取得する。UIは最大2,000行。
- 技術ログは資格情報redactorを再適用し、1行16KiBで切り詰める。任意パスは受け取らない。

## エラー処理

- ポップアウト切替失敗時は永続状態を変更せず元の表示を保つ。
- ログ未作成は空状態、読取失敗は再試行可能な非致命エラー。
- UI設定ファイルが未知・破損していても既定値で起動する。
- Live2D障害時は現在のchat配置に応じて会話画面を前面へ出す。

## 受け入れ

- 再起動後にテーマと会話配置が復元される。
- 切替中の会話に欠落・重複がない。
- ログ2タブが完全に分離され、ログ画面から送信や編集ができない。
- Windowsの100%、125%、150%表示倍率と明暗壁紙でキャラクター窓の矩形背景・境界・影が見えない。
