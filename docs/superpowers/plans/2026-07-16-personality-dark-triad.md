# Personality Dark Triad Controls Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** キャラクターごとに既存6種とダークトライアド3種の性格値、および明示同意が必要な強いダーク表現設定を編集・保存し、次の会話ターンから反映できるようにする。

**Architecture:** `pw-contracts` がv2ペルソナ契約と警告同意バージョンを所有し、desktop behavior層がv1互換読込・原子的保存・固定境界プロンプトを担当する。設定専用Tauriコマンドを介して独立したReact `PersonalityPanel` がキャラクター別ドラフトを編集し、設定ウィンドウだけに読書き権限を付与する。

**Tech Stack:** Rust 2024, serde, ts-rs, Tauri 2, React 19, TypeScript 7, Vitest, Testing Library, pnpm workspace

## Global Constraints

- 既存6項目と新規3項目は整数 `0..=100`、新規・v1移行時の既定値は50。
- `allow_intense_dark_expression` はキャラクターごとで既定OFF。
- ON保存には現在の `DARK_EXPRESSION_ACKNOWLEDGEMENT_VERSION` への明示同意が必要。
- LLM提供元の制約、上位システム指示、違法行為・自傷他害などの基本保護は解除しない。
- 保存成功後の次のユーザーメッセージから反映し、進行中の応答は変更しない。
- v1読込だけでは書き換えず、明示保存時のみ検証後にv2へ原子的置換する。
- 破損JSON、未知スキーマ、ID不一致を既定値で上書きしない。
- 警告・確認・免責文は設計仕様書の日本語を一字一句保持する。
- 新規依存パッケージを追加しない。

pub fn save_persona(
    layout: &AppDataLayout,

    profile.validate()?;
