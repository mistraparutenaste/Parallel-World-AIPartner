# Phase 1 Live2D表示 実装計画

**Goal:** Cubism SDK for Web 5-r.5を使い、透過Character WindowへLive2Dモデルを表示し、設定から表情・モーション・クリック透過を制御し、DPIと位置・サイズ復元を検証する。

**Architecture:** Reactはmount/status表示だけを担当し、React非依存の`@parallel-world/live2d-runtime`がcontrollerとCubism adapterを所有する。設定の正本はRustのversioned stateとし、Settingsだけがwrite、Characterはread/listenだけを許可する。プロプライエタリSDK/modelはhash検証済みのignored dev stagingへ置き、未承認assetをrelease bundleへ含めない。

**Authority:** `基本設計.md` Phase 1、`docs/superpowers/specs/2026-07-11-parallel-world-product-design.md`、`docs/superpowers/research/phase1-inventory.md`、`docs/superpowers/research/external-assets-audit.md`。
