# parallel-world Live2Dテスト素材取得タスク

## 目的

parallel-worldのLive2D描画、表情、モーション、物理演算、リップシンク、Cubism 5.3機能を検証するため、Live2D公式の無料サンプル素材と公式SDKサンプルを取得し、整理してください。

非公式サイト、転載サイト、出所不明のモデルは使用しないでください。

---

## 重要なルール

1. 取得元はLive2D公式サイトまたはLive2D公式GitHub Organizationに限定する。
2. 使用許諾への同意が必要なページでは、自動的に同意ボタンを押さない。
3. 使用許諾画面が表示された場合は、URLと契約名を報告してユーザーの確認を求める。
4. CAPTCHA、ログイン、利用許諾確認を回避しない。
5. ダウンロードした素材を公開Gitリポジトリへコミットしない。
6. 原本ファイルを直接編集しない。
7. ZIP原本、展開済み原本、アプリ組み込み用コピーを分離する。
8. 各ファイルのSHA-256を記録する。
9. ライセンスと配布元URLを必ず保存する。
10. 完了していない項目を完了扱いにしない。

## Phase 1：GitHubから自動取得可能な素材

### 1. CubismWebSamples

安定版タグ`5-r.5`を、サブモジュール込みで取得してください。

```bash
git clone \
  --branch 5-r.5 \
  --depth 1 \
  --recurse-submodules \
  https://github.com/Live2D/CubismWebSamples.git \
  third_party/live2d/CubismWebSamples
```

すでに同名ディレクトリが存在する場合は上書きしないでください。現在のリモートURL、タグ、コミットIDを確認し、同じ取得元である場合だけ更新してください。

取得後、次を記録してください。

```bash
git -C third_party/live2d/CubismWebSamples remote -v
git -C third_party/live2d/CubismWebSamples describe --tags --always
git -C third_party/live2d/CubismWebSamples rev-parse HEAD
git -C third_party/live2d/CubismWebSamples submodule status
```

### 2. MotionSync公開コンポーネント

MotionSyncは任意機能です。公開リポジトリの安定版タグ`5-r.2`を取得してください。

```bash
git clone \
  --branch 5-r.2 \
  --depth 1 \
  https://github.com/Live2D/CubismWebMotionSyncComponents.git \
  third_party/live2d/CubismWebMotionSyncComponents
```

注意：

```text
GitHubリポジトリだけではMotionSyncは動作しない。
MotionSync Coreを含む公式配布パッケージが別途必要。
```

### 3. ライセンスファイルの保存

次のファイルを各リポジトリから`project-input/live2d/licenses/`へコピーしてください。

```text
LICENSE.md
NOTICE.md
NOTICE.ja.md
README.md
README.ja.md
CHANGELOG.md
```

同名ファイルが衝突しないよう、以下のように名前を付けてください。

```text
CubismWebSamples-LICENSE.md
CubismWebSamples-NOTICE.md
CubismWebSamples-NOTICE.ja.md
CubismWebMotionSyncComponents-LICENSE.md
CubismWebMotionSyncComponents-NOTICE.md
```

## Phase 7：ファイル検証

各モデルについて、以下の有無を検査してください。

```text
*.model3.json
*.moc3
テクスチャ画像
*.physics3.json
*.pose3.json
*.cdi3.json
*.exp3.json
*.motion3.json
*.motionsync3.json
*.wav
```

すべてのモデルに全ファイルが必要なわけではありません。欠落ではなく「対象モデルでは未提供」と区別してください。

### 必須検証

各選択モデルについて、最低限次を確認してください。

```text
.model3.jsonがJSONとして読み込める
.model3.jsonから参照される.moc3が存在する
参照テクスチャが存在する
参照モーションが存在する
参照表情が存在する
参照物理演算ファイルが存在する
ファイル名の大文字・小文字が一致している
パスがモデルディレクトリ外へ逸脱していない
```

### リップシンク確認

次のパラメーターを検索してください。

```text
ParamMouthOpenY
ParamMouthForm
LipSyncグループ
```

結果を以下へ出力してください。

```text
project-input/live2d/reports/LIP_SYNC_COMPATIBILITY.md
```


形式：

```json
{
  "schemaVersion": 1,
  "generatedAt": "ISO-8601",
  "assets": [
    {
      "id": "live2d-haru",
      "name": "Haru",
      "sourceType": "official-github",
      "sourceUrl": "https://github.com/Live2D/CubismWebSamples",
      "sourceVersion": "5-r.5",
      "localPath": "project-input/live2d/selected/haru",
      "licenseCategory": "live2d-original-character",
      "intendedUse": ["local-development", "integration-test"],
      "redistributionApproved": false,
      "files": [
        {
          "path": "relative/path",
          "size": 0,
          "sha256": "..."
        }
      ]
    }
  ]
}
```

`redistributionApproved`は、明示的に法的確認が済むまで`false`にしてください。
