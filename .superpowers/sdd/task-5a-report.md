# Task 5A report: resolved persona prompts and user-turn interaction lease

## Scope

- Shared character catalog resolution between the manifest command and normal chat.
- Deterministic per-character persona prompt resolution and legacy fallback.
- Chat worker fingerprinting from the resolved persona and matching renderer capabilities.
- RAII user-turn lease carried through the submit, context, and conversation queues.
- No proactive worker, assistant-only persistence, IPC/UI/TTS/tray, or frequency adapter changes.
